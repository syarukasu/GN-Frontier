## 0.2.2 — 配布物と専用サーバー

確認日：2026-11-15。MODパックと専用コアの共通バージョンは0.2.2です。[配布ファイル](https://github.com/syarukasu/GN-Frontier/releases/tag/v0.2.2) / [機械可読の検証記録](../pack/validation-0.2.2.json)

- CurseForge ZIP・mrpack・サーバーZIPを生成し、全アーカイブのCRC、JAR同梱ゼロ、パスの重複、プライベートファイルの混入を検査。
- クライアント140項目、CurseForge manifest 132項目＋外部補完8項目、サーバー112項目の依存物が漏れなく対応。専用コアは1本。
- 第三者139ファイルは原版のサイズ・ハッシュと一致。選択したバージョン・URL・SHA-256を維持し、配布元139 URLの応答とサイズも確認。
- Pythonダウンローダーの9テストが成功。Windows PowerShell版は公式Modrinthからの実取得、取得済みファイルの照合、置き換え前のバックアップ、ハッシュ不一致時の既存ファイル保全を確認。
- ExfilZonesのクライアント用イベント登録と、Anomaly Zoneの依頼画面パケットの読み込み不具合をコアで補正。原版を使う検査で、サーバーイベント・コマンド・通信データ・受信完了処理の保持を確認。
- Windows / Java 17 / Forge 47.4.20の**専用サーバー**で、107本のJAR＋5個のガンパックを読み込み、`Done`、ハード難易度、保存、終了コード0を確認。
- 既存の登録済み検証ワールドを再利用。Lost Citiesプロファイルは`gn_azzz15flat_nature`。地図制限効果を保つためXaeroを共通側へ残し、最終構成では保存データの登録項目の欠落なし。
- KubeJSは起動スクリプト1本／サーバースクリプト4本ともエラー・警告0。レシピ181件追加・251件削除、失敗0。
- 検証後に専用環境のクライアント用MOD・設定を復元し、管理対象のハッシュを照合。元Prismインスタンスの起動・置き換え、画面・マウス操作は行っていません。

確認の限界・残件：

- CurseForge形式の外部URL補完は、インポート後のスクリプト実行が必要です。CurseForgeサイトの掲載・公開ID・アプリからの実インポートと更新は未完了。[配布方式と残件](CURSEFORGE.md)
- `.mrpack`はPrism向けのメタデータとアーカイブ検査まで。ランチャー画面からの実インポートは未検証です。
- Linuxのスクリプトを用意していますが、実サーバー起動の確認はWindowsです。参加クライアントとの接続、長期マルチ負荷、0.2.2での新規ワールド生成・画面表示は今回の検証範囲に含めていません。
- 元MODの任意連携・タグ・リソース警告、クライアント対象Mixinの探索時のログ、Rhinoのクラス探索ログは残ります。起動成功を「ログのエラー表示がすべて解消した」とは扱いません。
- 元Prismインスタンスは0.2.1のままです。配布用0.2.2の作成・検証と、元インスタンスへの導入を分けています。
