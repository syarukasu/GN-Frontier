確認日：2026-11-15。指定Prismインスタンスへ専用コア0.2.3と設定をバックアップ付きで導入済み。配布物は未公開です。[検証記録](../pack/validation-0.2.3.json) / [装備・数量データ](../overlay/kubejs/data/gnfrontier/npc_loadouts/catalog.json)

- **GN-085**：Expertの通常防具・防護エンチャント倍率を0に設定。ダメージタグとコア内の互換処理で、TaCZ銃弾の通常防御・防具強度・防護エンチャントによる軽減を無効化。防弾装備による軽減、弾種の貫通差、近接攻撃に対する通常防御を維持。
- **GN-086**：新規一般兵の支給装備を次の構成へ変更。既存の兵士は現在の銃を保持し、装備・携行品を一度だけ補います。

| 陣営 | 新規一般兵のTaCZ銃 | 防弾装備 | 予備弾 |
| --- | --- | --- | --- |
| 東 | AK-47 / RPK、T2照準器 | 6B47 / 6B43 | 90 / 120発 |
| 西 | M4A1 / SCAR-L / M249、ACOG | PASGT / IOTV | 90 / 90 / 150発 |

- 一般兵には包帯2個・レーション1個を基本支給。衛生兵は包帯6個・抗生物質1個・レーション1個。支援兵の既存の医療具・工具・拳銃は保持し、拳銃用の予備弾も支給。既存のスクラップ・医療品・通貨の抽選は生前の携行品へ移したため、基本支給より増える場合があります。
- 弾薬は実インベントリから消費。PMCの240発の一括スタックは数量を保って分割し、保存・再読み込み時の欠落を防止。
- 兵士・PMC・盗賊の死亡時には、装備と携行品を一つの共有遺体へ移します。右クリックで開き、残弾・照準器・耐久・固有NBTを保持して回収できます。致命弾での防弾装備の損耗も保存。死亡時の銃・追加弾薬の再抽選は停止しました。
- 未回収品がある遺体は保存。空になった遺体だけ1200ティック後に消去します。個人別lootの再生成は行いません。
- TaCZ Attributes Addonの品質は生前の携行時に元MODの処理で一度だけ確定。回収した瞬間に新しい性能が付くことを防ぎ、既存の品質や設定は保持します。
- **GN-087**：ラージチェスト画面を専用の遺体回収画面へ変更。装備6枠はすぐに確認でき、ポケット4枠と携行品44枠はそれぞれ「捜索」で順に判明します。既定値は品物1枠30ティック（20 TPS時1.5秒）、空き枠2ティック。各ワールドの`serverconfig/gnfrontier-server.toml`の`corpseSearch`で調整できます。
- 発見済みの内容と中断した品の進捗はプレイヤー別に保存。画面を閉じる・離れると捜索は停止し、再度開いた際は一時停止状態から再開できます。実際の携行品は共有で、未発見品のクリック・一括回収・交換などはサーバー側で拒否。発見前の携行品はメニュー同期にも載せません。
- 防具回収時に、東西兵のスキンへ描かれたヘルメット・ベストの面も頭部・制服の表示へ切り替える処理を専用コアに追加。元の死亡姿勢・腕脚・迷彩・残った銃の描画を使います。裸頭はMinecraft既定スキン、胴体は元の袖の布地を参照する代替表現です。
