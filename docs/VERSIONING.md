# バージョンの決め方

MODパックと専用コアMODは、どちらも `VERSION` に書かれた番号を使います。Gitタグは `v` を付けた番号です。管理開始は **0.2.1**。

| 桁 | 意味 | 0.2.1 の場合 |
|---|---|---|
| 左 | 最終回後の答え合わせ・正式リリースの段階 | 0 = 答え合わせ前 |
| 中央 | 再現対象として対応を進めている動画の回 | 2 = 第2回まで |
| 右 | 同じ動画範囲に対する更新回数 | 1 = 更新1回目 |

同じ動画範囲の修正は `0.2.2`、`0.2.3` と進めます。次の動画へ進めた最初の更新は `0.3.1` とします。最終回後に答え合わせを行い正式リリースするときに左を1へ上げます。左が1になっただけで未確認事項が消えた扱いにはせず、更新履歴と確認記録を残します。

これは一般的なSemVerの「機能追加／破壊的変更」とは異なる、この再現パック固有の番号です。動画の回数は対応範囲を表し、全要素の完全一致を保証しません。

`python tools/project.py version 0.2.2` で共通番号とパック表示設定を更新します。既存タグを付け替えず、変更内容を `CHANGELOG.md` に追記し、確認後に次のタグを作ります。旧 `0.1.0-dev.*`、`0.1.0-alpha.*`、`r*` はローカル作業の履歴として保持します。
