# 武器修理キット

**GN-101 / 開発版0.2.10**。既存商品の武器修理キットに、専用コアでTaCZ修理を追加しています。元MODの特定状況は[提供元調査](../pack/repair-kit-source-0.2.10.json)、確認した範囲は[検証記録](../pack/validation-0.2.10.json)を参照してください。

## 使い方

1. PDAで武器修理キットを購入します。商品は1個$300です。
2. 使用可能なホットバーにキットを置き、主手に持って空中を右クリックします。
3. 「銃器整備」で所持する銃を選びます。現在の耐久と補修後の値が表示されます。
4. 「キット1個で補修」を押します。サバイバルでは1個を消費します。満タンと不足時は補修できません。

選択画面でアイテムを移動する必要はありません。5枠ホットバーと通常の所持品欄にある銃が対象で、無効な4枠・オフハンド・防具欄は対象外です。クリエイティブでもキットの所持が必要ですが、補修時の個数は減りません。

## 対象と保持するデータ

GunDBで耐久が有効になっている、登録済みのTaCZ銃が対象です。耐久を持たない銃やバニラの道具には使えません。キットの既存IDは`hbm_m:gun_kit_2`のまま保持し、原MODの汎用Itemを変更せず、専用コアのイベントと画面で扱います。

銃本体の`Damage`だけを変更します。弾倉・薬室の弾、アタッチメント、品質と補正、その他のNBTは保持します。既存のジャム状態・熱・アタッチメント自身の摩耗は変更しません。

## 設定

新規ワールドの既定値は`defaultconfigs/gnfrontier-server.toml`、各ワールドで使う値はそのワールドの`serverconfig/gnfrontier-server.toml`にあります。既存ワールドは次回の読み込み時にForgeが不足項目を補完します。

```toml
[weaponRepairKit]
enabled = true
restorePercent = 25
```

`restorePercent`は1〜100。1回につき最大耐久に対する割合を回復し、端数は切り上げ、最大値を超えません。残りの損耗が回復量より小さくてもキット1個を使います。処理と消費の判定はサーバーで行います。

## 動画との対応

Part1 07:54で武器修理キットの黒いケースと$300の価格を確認しています。外観は手作業の模写です。動画内のアイテム提供元、修理操作、消費数と回復量は未確定です。今回の選択画面と25％は専用MOD側の暫定実装であり、確認できた原仕様として扱いません。

実機ではM4A1（最大1000）とマカロフ（最大800）を3回ずつ補修し、弾数・薬室・ACOG・ネイティブ品質データを含む耐久以外のNBTの一致を確認しました。統合サーバーでの確認で、専用サーバーや長時間マルチプレイの確認は含みません。
